🦞 OpenClaw 安装

Windows 用户

1

点击下载 install-openclaw.bat

2

找到下载的文件，右键 → 以管理员身份运行

3

脚本会自动检测 Node.js → 安装 OpenClaw → 启动配置向导

4

按提示完成初始设置，即可开始使用

Mac / Linux 用户

1

下载 install-openclaw.sh

2

打开终端，进入下载目录

3

执行：bash install-openclaw.sh

⚠️ 如果尚未安装 Node.js，Windows 版脚本会自动下载安装。Mac/Linux 请先前往 nodejs.org 安装 Node.js v18+。

🤖 Claude Code 安装

Windows 用户

1

点击下载 install-claude-code.bat

2

右键 → 以管理员身份运行

3

安装完成后，终端输入 claude 启动对话

💡 Claude Code 需要 Anthropic 账号及 API Key。安装完成后运行 claude 按提示登录即可。

❓ 常见问题

Q：安装时提示"禁止运行脚本"？

Windows 可能会拦截未签名的脚本。右键点击 .bat 文件 → 属性 → 勾选"解除锁定" → 确定，再重新运行。

Q：安装速度很慢？

npm 包需要从外网下载，速度取决于网络环境。首次安装建议耐心等待 3-5 分钟。

Q：安装完成后怎么用？

在终端（CMD/PowerShell）输入 openclaw -h 查看全部命令。openclaw setup 可重新配置。

Q：安装包安全吗？

安装包是纯文本脚本，不包含任何可执行二进制文件，安全透明。OpenClaw 和 Claude Code 均为官方开源项目。
